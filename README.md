# Advanced SQL Analytics | SQL Data Analytics Project

## Project Overview
This project focuses on performing advanced sales and product performance analysis using SQL. It explores sales trends over time, evaluates product performance, compares yearly sales, and analyzes category contributions and customer spending patterns.

The project uses advanced SQL techniques to transform raw sales data into meaningful business insights and identify trends, performance differences, and revenue contributions.

## Project Objectives
- **Monthly Sales Analysis:** Analyze monthly sales trends using date-based functions and identify changes in sales over time.
- **Yearly Sales Analysis:** Evaluate yearly sales performance to understand business growth and sales patterns.
- **Cumulative Sales Analysis:** Calculate cumulative sales and running totals to track sales progression over time.
- **Product Performance Analysis:** Calculate yearly sales for each product and compare them with average product sales.
- **Performance Comparison:** Identify differences between current and average sales performance and compare current sales with the previous year's performance.
- **Category Sales Contribution:** Analyze the contribution of different product categories to overall sales.
- **Product Cost Segmentation:** Categorize products into cost-based segments for further analysis.
- **Customer Spending Segmentation:** Classify customers based on their spending behavior to understand customer value.
